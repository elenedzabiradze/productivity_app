# Project Guidelines

## How to work with me
- I'm new to coding. Explain what you're doing in plain language before making changes, not just after.
- Always ask before deleting files or overwriting existing work.
- Keep changes small and scoped — if a task seems big, break it into steps and check with me between them.
- When something breaks, show me the actual error message and explain what it likely means before fixing it.

## Code style
- Prefer simple, readable code over clever shortcuts.
- Add brief comments explaining non-obvious logic.

## This project
- This is a learning sandbox for practicing agentic coding, eventually building toward a productivity-tracking desktop app.
